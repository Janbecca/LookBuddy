# LookBuddy 双端演示手册

日期：2026-10-10。每端约 2 分钟，先排练再录制；本文件不是实机验收证明。

## 演示边界

真实模式：Web / Electron 用本地摄像头感知，遵守真实时间、展示预算与用户参数。Android 当前只消费后端结果，不运行手机视觉识别。桌宠是桌面容器内独立悬浮窗口，外观仍为占位。

回放模式：按钮明确写着“加速时间，仅 demo 数据”，使用模拟语义观察验证同一个后端闭环。它不向 live 写入视觉结果，也不会在悬浮桌宠上伪装成摄像头触发的真实提醒。20 秒恢复、随后 2 分钟观察、5–20 分钟休息和 30–90 分钟久坐不能压缩后宣称真实完成。

演示能证明：两类工程闭环、缺帧 / 椅子移动的保守判定、学习参数更新与隔离、跨端配置与查询。不能证明：真人识别准确率、真实情绪改善、长期有效性、因果效果或官方设备接入。

## 开场前准备（不计入 2 分钟）

1. 构建完成、准备专用演示账号，两端登录同一账号；不要用真实敏感数据。使用独立演示数据库，避免混入日常使用记录。
2. 固定久坐 60 分钟、起身目标 10 分钟（全量回放排练可临时选 5 分钟减少请求量），忙碌关闭。正式计时不要再改阈值。预热本地模型、允许摄像头、校准正常姿态。全身 / 腿部不可见时不承诺起身可验证。
3. Android 先实际安装 APK，配置可达地址并验证登录。当前开发环境未完成此步骤；没有设备时只能演示 Kotlin HTTP 测试，不把它称为 Android 界面演示。
4. 关闭学习，确认回放 `recovery` 返回 `improved`；`chair` 返回 `unknown`；`expression_relaxed` 返回同名结果。确认 live 奖励没有增加。然后按需重置本账号 demo 数据，重置仅用于专用账号，会删除 demo 证据。
5. 计时前安排好屏幕：主窗口调试入口、JSON 输出区、桌宠和 Android。不要在两个真实感知端同时开启摄像头；推荐只让 Electron 采集，Android 查询。

## 启动与只读检查

在项目根目录打开三个 PowerShell 终端。独立演示数据库会正常保存演示账号和记录，不自动删除。

终端 A（本机演示）：

```powershell
cd apps/backend
$env:LOOKBUDDY_DATABASE_URL='sqlite:///./lookbuddy-demo.db'
.\.venv\Scripts\python.exe -m uvicorn lookbuddy.main:app --app-dir src --host 127.0.0.1 --port 8000
```

终端 B（开发容器）：

```powershell
$env:LOOKBUDDY_BACKEND_URL='http://127.0.0.1:8000'
pnpm dev:desktop
```

或启动已有便携构建，必须保留 EXE 同目录全部文件：

```powershell
$env:LOOKBUDDY_BACKEND_URL='http://127.0.0.1:8000'
& '.\apps\desktop\release\LookBuddy-win32-x64\LookBuddy.exe'
```

浏览器 Web 单独演示时改用 `pnpm dev:web`，地址为 `http://127.0.0.1:5173`；不要同时启动第二路真实采集。Electron 默认本地地址为 `http://127.0.0.1:5189`。

终端 C：

```powershell
.\apps\backend\.venv\Scripts\python.exe scripts/demo_preflight.py --backend http://127.0.0.1:8000 --frontend http://127.0.0.1:5189 --adb C:/Users/dgxx4/AppData/Local/Android/Sdk/platform-tools/adb.exe
```

浏览器演示把 `--frontend` 改为 `http://127.0.0.1:5173`。`--offline` 只检查本地文件；正式双端开场加 `--require-android`，缺少授权设备即返回失败。退出码 0 仍可能有 WARN，表示局部准备就绪，不代表完整验收。

脚本不登录、不启动摄像头、不写业务数据、不安装软件、不读取密钥；仅检查文件、GET 健康 / HTML 和 `adb devices`（ADB 可能启动其本地守护进程）。HTTP Date 对比只证明粗略服务器时钟，不证明视频连续性或完整实时窗口。也不证明两个 URL 指向同一数据库，跨端同账号核对才是证据。

Android 模拟器地址为 `http://10.0.2.2:8000/`。真机用同一受信局域网主机 IP，并按需将后端绑定到该网卡 IP；防火墙调整须另行确认。不要为演示关闭整个防火墙，不使用敏感数据。远程用 HTTPS。官方 AAR / T8171 未接入。

## Web / 桌面容器：120 秒脚本

| 时间 | 操作 | 说明与证据 |
|---|---|---|
| 0–20s | 展示已启动的真实摄像头、校准状态，隐藏主窗口再从桌宠打开 | 桌宠是桌面容器；只有主窗口拥有感知链。状态形象占位，不是成品视觉。 |
| 20–45s | 明确说“下面是加速回放”，关闭学习，运行姿态恢复 | JSON `namespace=demo`、`status=improved`；解释正常保持 20 秒再观察 120 秒，而非点击接受就算完成。 |
| 45–60s | 运行“坐椅平移离开”或“后续缺帧” | `unknown`；不把消失或未知当作完成 / 负反馈。 |
| 60–85s | 运行“陪伴后表情线索放松” | `expression_relaxed`；只展示视觉线索前后变化，不说“识别出抑郁”或“治愈情绪”。抓拍自评用于校正标签，不作为满意度反馈。 |
| 85–110s | 先看模拟模型参数，再开启学习运行一次姿态恢复；查询奖励和下一次选择 | 参数有版本和更新次数；概率变化不保证下一次选固定动作。样本稀疏时保留规则冷启动与硬预算。 |
| 110–120s | 展示 live / demo 隔离，再从桌宠暂停 | live 未被回放训练；暂停释放摄像头。完整记录在后端，可跨端查询。 |

学习段请用重置过的专用账号：冷启动默认策略固定，之后 Thompson Sampling 有随机性。若选择 `silent`，说明“系统决定暂不打扰”；该结果也是设计的一部分。不能通过反复重跑挑选有利结果来证明算法优越。

## Android：120 秒脚本（需设备可用）

| 时间 | 操作 | 说明与证据 |
|---|---|---|
| 0–20s | 展示连接状态、同账号偏好，改忙碌并在桌面控制台执行 GET `/v1/preferences` 核对 | 实际服务端配置共享；不是 Android 本地视觉识别，也不假设桌面控件会自动刷新。恢复忙碌关闭。 |
| 20–45s | 在 demo 命名空间，关闭学习，运行姿态恢复 | 同一后端规则，返回 `improved`，查看干预记录。 |
| 45–60s | 运行起身后提前返回或椅子滑动 | `interrupted` / `unknown`，显示动作完成与持续改善分开。 |
| 60–85s | 运行表情放松回放，查看表情与干预 | 弱证据；不弹满意度问卷，不伪装手机摄像头识别。 |
| 85–110s | 查看 demo 奖励 / 参数，再切 live 对照 | 同账号查询 Web 产生的记录；实时消息触发补查，断线有前台轮询兜底。 |
| 110–120s | 展示当日日记或已有日记，再切后台 | demo 不污染真实日记；没有真实事件时内容可为空。后台停止周期轮询与连接，不宣称后台感知或通知。 |

真实提醒的 Android 演示是可选预备素材：须由 Web 的真实观察触发；先点“显示并登记”，预算通过才显示正文。拒绝显示、他端已响应、断线等都展示实际结果。不要手工写未来 live 时间戳或缩短 15 分钟硬间隔制造频繁提醒。

## 回放核对表（关闭学习）

| 场景 | 期望结果 |
|---|---|
| recovery / recurrence / gap | improved / recurred / unknown |
| chair / break / return | unknown / improved / interrupted |
| ignored / snoozed | ignored / snoozed |
| expression_relaxed / expression_tense / expression_unchanged / expression_gap | 同名结果 / 同名结果 / 同名结果 / unknown |

打开学习后固定期望表不再适用于所有响应场景：`silent` 没有可接受 / 延后的消息，可产生 `unknown`。检查决策解释而非硬凑期望。

## 故障与退出

- 健康检查失败：确认后端终端没有异常、端口与两端 origin 一致。不要把 5173 / 5189 当 Android 后端地址。
- 模型文件存在但摄像头失败：检查权限、其他软件占用、可见区域；停止真实演示并明确切回加速回放。不能将合成摄像头日志当真人证据。
- 学习不更新：先确认勾选学习、查 demo 奖励 / 参数，确认没有缺帧 / 未知结果；不要修改 live 账本。单次后验变化不等于长期证明。
- Android `unauthorized`：在设备确认调试授权；不要自动启用开发者模式或绕过设备授权。
- 结束：桌宠暂停 / 退出释放摄像头，退出 Android，手动 Ctrl+C 关闭本次后端。保留演示数据；删除账号或重置 demo 前确认目标账号。旧便携版本保留在 `apps/desktop/release/LookBuddy-win32-x64-before-P6-20261010`。

## 正式验收仍缺少

实际 Android 安装与滚动操作、旋转 / 前后台恢复、Keystore；真人摄像头、光照 / 角度 / 不同用户、起身与椅子滑动准确率；真实时钟下完整 20+120 秒闭环、配置的离岗时长；多屏 / 锁屏 / 休眠；官方 SDK、Router 鉴权与模型、正式签名。

演示评价：工程闭环和可解释学习可展示，调试界面适合技术验收；当前不具备“成熟产品体验 / 算法有效性已验证”的演示证据。完成上述实机验收后才能判断现场表现。
