# P2 自适应策略、展示预算与延后调度

日期：2026-10-08  
状态：代码与自动化验收通过；真实长期效果、情绪观察、桌面容器和 Android 联调未验收

## 当前决策链

当前视觉快照 → 用户配置 / 忙碌 / 活跃干预 / 真实展示预算过滤 → 候选优先级 → 有限情境 Thompson Sampling → 干预方式及下一次间隔 → 展示回执或静默观察 → 视觉动作结果 / 自然交互 → 增量奖励及学习状态。

久坐阈值和休息时长仍由用户配置，不由模型擅自修改。饮水 / 疲劳也通过同一展示预算；它们当前没有完整的视觉结果验证，只能使用已有自然响应，不能伪造完成或持续改善。

## 展示规则

- 所有类型共用最短 15 分钟间隔、滚动 60 分钟最多 3 次主动交互。
- 按实际展示回执计数，创建候选和未成功展示不计数；重复回执不重复计数。
- SQLite 写事务及用户级锁串行化预算判断，测试验证并发两次回执只有一次获准。
- 未展示候选最长保留 10 分钟，过期释放观察状态，不产生忽略奖励。
- Web 在收到展示许可后再显示卡片；忙碌或能力关闭时不能新展示。
- 模型选择的 15 / 30 / 60 / 120 分钟表示本次决策之后的下一次交互间隔，不能缩短规则下限。
- “暂不打扰”不创建可见卡片、不消耗展示次数，但会继续观察自然变化，并按所选间隔节制再次决策。

## 学习算法与适用边界

策略与间隔采用两个有限选择阶段。姿态策略为轻提示、短伸展、短休息、暂不打扰；久坐策略为短休息、短伸展、暂不打扰。短伸展不替代用户规定的起身休息目标。

情境按用户时区的时间段、视觉候选类别和最近一小时交互负担分组。反馈历史反映在每个策略的参数中；某情境少于 5 次参数更新时回退到该用户同类场景的汇总历史。没有历史时使用固定保守初值，不需要预先训练数据。

每次选择记录 alpha / beta、情境、回退、策略、间隔和版本。历史证据采用 7 天半衰期。奖励采用分数权重更新 Beta 参数，是针对稀疏反馈的实用在线方案，输出不是校准过的成功概率。

选择概率通过每阶段 256 次后验采样估计，并标注为估计值；不能直接作为精确 propensity 进行无偏离线策略评估。当前情境粒度较粗、采用分阶段近似；长期效果仍需实际用户数据和对照评估。

## 奖励 v1

| 分项 | 初始权重 | 更新对象 |
|---|---:|---|
| 接受 | +0.05 | 干预方式 |
| 动作验证完成 | +0.25 | 干预方式、间隔 |
| 持续改善 / 起身及离岗时长达标 | +0.75 | 干预方式、间隔 |
| 姿态复发 | -0.25 | 干预方式、间隔 |
| 明确忽略 / 关闭语义 | -0.60 | 干预方式、间隔 |
| 延后 | -0.10 | 仅时机；不惩罚干预方式 |
| 已知结果下的展示成本 | -0.05 | 干预方式、间隔 |
| 未知 / 观察不足 / 提前返回 | 无新增负奖励 | 保留已证实的分项，不假设厌烦 |

这些是版本化开发初值，可通过 `/learning/config` 查看；当前不开放任意在线修改权重。未知结果不会扣除已验证的动作收益，也不会自动增加打扰。表情弱反馈尚待 P3，不纳入当前奖励。

奖励账本按原干预链和分项唯一结算。延期重试关联 rootId / parentId，后续完成归因给原链；重复样本、重复响应和多个重试子链不会重复领取同一完成收益。旧 P1 决策不追溯训练新模型。

## 延后调度

延后请求持久化为任务。后台每约 2 秒处理到期任务，启动后恢复已有 pending 任务；读取 pending 提醒、提交新快照也可推进调度。

再次提醒至少同时满足：用户延后时长已到、当前全局预算允许、未忙碌、会话有效、没有其他活跃干预、同会话 30 秒内的有效在岗快照仍有对应触发条件。

用户选择延后 10 分钟，并不允许违反 15 分钟硬间隔；任务会记录 budget 延迟原因。用户已开始动作时推迟再提醒，完成动作后取消重调度。状态恢复、功能关闭、会话结束或超过 24 小时也取消。

延期期间仍能观察自然调整。到期重提醒使用新 ID，但保留原干预链及原策略。Web 定期查询 pending 获取到期提醒；后续 Android 接入同一查询接口。当前演示用显式模拟时钟，真实调度不采用未来摄像头时间。

## 调试 API 与操作

| 接口 | 用途 |
|---|---|
| GET `/v1/learning/config` | 算法、规则和奖励定义 |
| GET `/v1/learning/states?namespace=live或demo` | 学习参数 |
| GET `/v1/learning/rewards?namespace=live或demo` | 奖励账本 |
| GET `/v1/learning/preview?category=posture&namespace=demo` | 随机预览下一次策略，不创建提醒；不替代完整规则评估 |
| GET `/v1/scheduler/jobs` | 任务状态、dueAt、延迟 / 取消原因和 dispatchedId |
| POST `/v1/debug/interventions` | 增加 `learning=true` 开启独立 demo 模型；可选 seed 只用于模拟复现 |
| POST `/v1/debug/interventions/{id}/respond` | 模拟接受 / 忽略 / 延后；拒绝修改真实干预 |
| POST `/v1/debug/learning/reset` | 仅清理当前账号 demo 干预、观察、奖励及模型，真实记录保留 |

Web 勾选“更新独立 demo 模型”，运行闭环或响应回放，再查看模型参数、奖励账本和选择预览。连续忽略会降低原方式 / 间隔的后验收益；选择是概率分布变化，不保证每次立即切换。静默策略没有消息可忽略，模拟此情况返回未知且不生成拒绝奖励。
