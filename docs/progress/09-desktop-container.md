## 单感知链及安全边界

调试窗口是唯一感知拥有者，且禁用后台节流；桌宠既无摄像头又无业务 API / 登录令牌权限，使用独立非持久会话。主进程只中转限制长度的状态文本、七类标签、提醒 ID 和固定控制指令；原始画面、抓拍、关键点和令牌不跨窗口。

普通运行使用单实例锁及固定监听端口。IPC 校验窗口归属、主 frame、origin、字段和当前提醒；未知指令、过期提醒和桌宠发布状态会拒绝。权限只对主窗口本地视频询问授权，音频、桌宠及其他权限拒绝。Node integration 关闭，sandbox、contextIsolation、webSecurity 开启，导航、新窗口、网络及 CSP 限制生效。

后台地址接受本机 HTTP 或远端 HTTPS，不接受内嵌凭证和路径前缀。所有本地请求有 Host / Origin 校验。移除外部字体依赖，模型和 WASM 全部使用已存在的本地资源。策略参照 [Electron 官方安全清单](https://www.electronjs.org/docs/latest/tutorial/security)，不是正式发布安全审计。

补充启动 / 暂停代际校验：暂停后，延迟的摄像头授权流立即停止，不重新附加到 video；过期 tick / 提醒查询不再恢复干预。播放失败释放轨道，保存图片的异步结果不恢复已暂停预览。Windows 隐藏启动时首个 ShowWindow 可能被系统抑制，显式重开现已兼容。

正常退出会销毁渲染进程及摄像头；异常渲染进程退出时容器一起退出，防止留存失去控制的桌宠。强制退出不承诺最后的后端会话结束请求必达；暂停路径正常请求结束会话，缺失视觉仍由未知结果保护。
