# P6 演示准备与证据

日期：2026-10-10。状态：演示准备完成，现场 / 真机验收未完成。

## 用户链路

桌面 / Web 调试控件 → API → 独立 demo 观察及干预 → 结果 / 学习参数 → 调试输出；Android 使用相同后端，桌宠由唯一主窗口控制。

依据 verification 技能逐层核对，明确“文件 / 健康 / 时钟检查”“真实 HTTP 回放”“合成摄像头”“真人设备”分别提供什么证据，不将接口测试视作界面实机验收。关联 env-vars 指导只用于配置与密钥边界：没有关联 Vercel、拉取云端环境、读取密钥或改部署。

## 交付

- `docs/demo-runbook-20261010.md`：Web / 桌面容器、Android 各 120 秒脚本、启动命令、12 场景期望、故障处理与验收清单。
- `scripts/demo_preflight.py`：仅文件、GET 健康 / HTML、HTTP Date 时钟及授权设备检查；可离线运行；可要求 Android 设备。0 退出码不等于完整验收。
- `scripts/test_demo_preflight.py`：origin 防误配、时钟、ADB 授权状态解析 3 项单测。
- Web 姿态回放在创建干预失败时也结束已创建工作会话；清理失败保留原始异常；4 项回归覆盖创建失败、采样失败、清理失败及正常忽略路径。
- Web HTTP 集成测试扩展为 12 场景，固定结果使用关闭学习的回放；学习单独验收，避免随机 `silent` 被误报失败。
- `scripts/check.ps1` 在 native 命令非零退出时明确终止，并包含 Web / 桌面 / Android 测试与 Lint；不再仅靠 PowerShell ErrorActionPreference 判断外部工具成功。
- 重新生成 Windows 便携容器，旧版本保留在 `apps/desktop/release/LookBuddy-win32-x64-before-P6-20261010`；Android APK 继续使用 P5 已构建版本，接口重新回归。

## 首个发现及修正

全量回放最初在 `snoozed` 期望失败：已开启学习可能抽中 `silent`，后端正确返回 `unknown`（没有可延后的消息）。没有改规则制造固定答案，而是将固定闭环与学习测试分离。演示手册明确说明静默动作和策略随机性。
