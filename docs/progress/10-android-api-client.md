# P5 Android API 接线与跨客户端同步

日期：2026-10-09  
状态：Debug APK、网络单测及真实后端集成通过；Android 模拟器 / 真机界面与官方 SDK 未验收。

## 本轮交付

- 将静态提示替换为真实登录 / 注册、可配置后端 origin、用户参数、待处理提醒、响应、干预 / 表情 / 时间线、学习 / 奖励 / 调度、日记与账号删除。
- Compose 只提供调试控件和 JSON 控制台，没有完整页面设计。未伪造手机视觉识别，`EufySdkGateway` 与官方 AAR 放置目录保持不变。
- ViewModel 管理生命周期及状态；Repository / Retrofit / OkHttp 管理请求、单次令牌续期、会话归属与实时连接。Android Keystore AES-GCM 加密会话；密码不持久化、令牌不写请求日志或控制台。
- 后端 WebSocket 新增 Bearer 请求头支持，兼容旧 query token，拒绝不存在 / 已删除账号。保留 FastAPI 架构，不迁移部署；此选择遵循后端架构技能的现有框架优先原则。
- 前台实时消息触发补查，周期性轮询作为断线恢复。后台关闭连接与周期轮询；没有后台通知、后台视觉感知或 Android 悬浮桌宠。
- 提醒正文在用户点“显示并登记”并通过服务端预算后呈现；响应复用 ID，不重造动作完成。冲突 / 已处理 / 预算拒绝显示失败并刷新状态。
- 12 种 demo 回放：姿态恢复、复发、断流、椅子滑动、完整起身休息、提前返回、忽略、延后，以及四种表情结果。使用相同后端时序验证及独立 demo 模型。
- 修复 Retrofit `Response<Unit>` 的删除失败处理：HTTP 非成功不能假报删除成功或清空有效登录。

## 验证

- 后端 49 项测试通过，包含新增 WebSocket 请求头、旧 query 兼容、无效令牌及删除账号拒绝连接。
- Android 8 项网络单测通过：origin / API 路径限制、续期、并发刷新去重、刷新失效 / 5xx、退出后旧刷新不恢复、控制台令牌保护、失败删除。
- 另一个可选集成测试实际执行通过，使用 Android 的同一 Kotlin 网络和回放实现调用运行中的 FastAPI，不是替代实现。覆盖 12 种回放、配置跨客户端、请求头实时消息、提醒显示 / 幂等 / 冲突、学习隔离、日记与 demo 重置。
- Debug APK 构建通过，产物 `apps/android/app/build/outputs/apk/debug/app-debug.apk`。
- Android Lint 通过（0 错误、4 警告）；提示为同步持久化、依赖更新建议、旧版备份配置检查及暂缺应用图标。备份在新旧 Android 版本均显式禁用（`allowBackup=false`、`fullBackupContent=false` 及新版排除规则）；Lint 仍保留兼容配置提示，待设备验收复核。
- Windows JDK 17 中文路径造成的测试类加载问题通过 ASCII 临时运行 classpath 修复；没有搬动项目源文件。
- 实时连接和周期刷新以服务端为准，测试账号自动删除；独立后端服务与测试数据库清理。

## 局限与下一步

当前 Android SDK 目录有构建工具，但没有可用 AVD / 系统镜像，也没有连接设备。因此不能把 APK 构建和 JVM 接口测试当作安装 / Compose 界面操作 / Keystore 实机验收。仍需验证网络地址输入、纵向滚动与提醒操作、旋转 / 后台恢复，以及真实设备资源和权限。

正式 release 后端仍是无效占位，禁止明文传输；未签名正式发布。官方 AAR、设备与鉴权未提供，保留扩展接口。

下一阶段 P6：准备 Web / Electron 与 Android 各约 2 分钟的演示流程、回放数据和启动检查；实际设备或模拟器可用时再做界面联调。表情假设与加速回放只证明工程闭环，不能证明真实情绪改善或长期有效性。
