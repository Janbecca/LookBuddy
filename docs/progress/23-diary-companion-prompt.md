# 工位日记陪伴语气

日期：2026-10-17。

先设计日记写作提示词，再按用户“约束太多、语气润色太少”的反馈重写。完整提示词位于 `apps/backend/src/lookbuddy/diary_prompt.py`，由 `DiaryWriter` 作为system消息使用；日期和真实记录另放user消息。备注继续作为素材处理，不成为system指令；内部候选评分、reasonCodes不发送给模型。

写作角色是愿意记住普通小事的工位伙伴，声音像桌边小纸条：亲近、轻松、细腻、有分寸。通过具体小事、长短句与停顿、接住用户主动表达的感受、轻而不过度的欣赏、有余温的收尾来建立陪伴感。提示词含饮水、用户自述疲惫、收尾三类语气示例，并明确示例不是本次事实。必要事实边界集中在最后一小段。

正文通常120—220字、两三个短段落；记录少可写短。模型不可用时的模板与空记录文案同时改为温和语气，但generatedBy仍准确标记template/template_fallback，不把模板当成在线模型成功。历史日期使用“这一天”，不一律称今天；未修改日记筛选、已有用户编辑保护或App按钮调用链。

验证：`pytest -q tests/test_diary_prompt.py tests/test_llm_service.py`，13 passed。覆盖系统/用户消息分离、备注保真、内部评分不外发、选定日期、模型成功及失败来源、无记录不调用模型。未调用真实供应商，未部署线上，未重建APK（提示词为后端代码）。
