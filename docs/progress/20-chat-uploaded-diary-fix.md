# 聊天与工位日记修复

日期：2026-10-17。基线：`main@816d3541d22f5b7c0f72477a20bc34f44bd667d7`。
工作分支：`codex/chat-diary-upload-fix`。Android：`1.4.1-chat-diary`，versionCode 11。

## 问题与修复

- 旧聊天页仅保存未发送消息，没有请求模型。新增需登录的 `POST /v1/buddy/chat`，复用现有关心语模型配置；App 发送当前消息与最近两轮成功对话。成功必须返回 `source=llm`，未配置、供应商失败、超时均明确报错，保留原消息，可重试或重新编辑。不存储服务端聊天历史。
- 事件已可通过 `payload.imageDataUrl` 存图片，但旧日记只读取 SDK 引用。日记接口增加 `hasUploadedImage`，需登录且按拥有者隔离的 `GET /v1/diary-images/{event_id}` 读取单张图片。沿用现有事件存储，不新增表、不迁移测试记录，不把图片发送给文本模型。
- App 展示已上传图片缩略预览，可点开查看，无需官方设备登录；限制输入大小并采样解码。兼容旧后端：按日记事件 ID 匹配 `/v1/timeline?limit=500` 中的 `payload.imageDataUrl`。达到500条会说明更早图片的兼容边界；新版后端按事件读取，无此限制。
- 未连接官方账号时，入口改为“刷新当天云端记录”，刷新文字及已上传图片；已连接时再同步官方设备历史。说明文字区分云端图片与官方 SDK 图片、录像。
- 日记接口按完整事件时间倒序返回，带 `occurredAt`，同一分钟内也能区分先后。App 兼容旧接口的 HH:mm 并重新排序，示例时间轴也倒序。不改变其他统计接口的排序。
- 日记页展示在线模型、模板或模型调用失败后的模板降级来源。日记当天无足够可用结构化事实时仍使用模板，图片展示成功不代表图片参与模型分析。
- 隔离联调显式关闭共享模型配置，避免测试调用真实供应商。
