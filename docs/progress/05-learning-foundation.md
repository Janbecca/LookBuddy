## 已实现

- `GET/PATCH /v1/preferences`：久坐 30/60/90 分钟（默认 60）、休息 5/10/15/20 分钟（默认 10），忙碌、姿态和陪伴开关；部分更新和错误配置校验。
- 现有规则读取久坐阈值 / 忙碌 / 姿态开关，全局冷却初值改为 15 分钟。
- 新增用户配置、干预链、观察、策略状态、奖励账本和迁移版本表；启动时非破坏性创建缺失表，不修改 / 删除旧表或数据。
- 契约由后端 Pydantic 机械生成至 `packages/contracts/schemas`，规划中的观察与干预契约明确标为基础定义。
- Web 配置控件与带认证的 API JSON 控制台。
- 姿态五分钟占比按有效观察时长计算；缺帧 / 未校准不当作健康姿态；有效窗口不足 30 秒不提交占比触发。
- 防止异步 tick 重叠、同一视频帧重复推理；重新启动清理计时，重新校准清理姿态窗口。
