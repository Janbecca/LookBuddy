# 聊一聊前端（1.6.0）

设计来源：LookBuddy Page 2 / 首页-聊一聊 `299:3996`；日记页气泡入口 `354:4094`。

- 疲劳/开心/关心提醒气泡的“聊一聊”、日记页Buddy旁的“和我聊一聊”进入同一页面。
- 饮水/久坐/坐姿的按钮为“好的”，仅关闭本条提醒、恢复默认IP，不认定用户已完成动作。
- 聊天是首页和日记页上层的页面，未新增底部Tab；Android返回回到进入前的页面，底部三个Tab可以正常跳转。
- 背景、Buddy头像、参考用户头像及日记聊天气泡轮廓使用下载后的原始Figma素材，运行时无临时素材URL。
- 复用现有LXGW字体和三Tab导航。Figma中的iOS系统栏采用Android原生系统栏；旧设计里的信号Tab沿用当前产品三Tab约定。
- 消息列表可滚动、输入框可多行、键盘显示时避让，发送空白无效。聊天内容不受主动提示30字符限制。
- 草稿、当前页和未发送内容保留于Activity可恢复状态；返回/切Tab不丢失，不上传、不写入磁盘聊天历史。
- 聊天API尚未接入。发送后只在本页显示用户内容和“暂未发送”，不伪造Buddy回复或发送成功；连接状态有明确提示。
- 参考用户头像为设计占位，后续接用户个人头像。设计截图预览中的五个空白气泡仅用于比对Figma；正常页面不会伪造历史对话。
- 首页正式后端事件接收、问候与日记推送、日记推送的真实接收保持原进度，本次先交付聊天页面与可操作的入口。

1.6.1：删除首页独立聊天入口，首页仅疲劳/开心/关心气泡进入聊天。七类动画按原始映射接入、可见高度统一为现有饮水约193dp；默认态不改。早晚问候无按钮、6秒后关闭；日记就绪预览以去看看进入日记。触发与正式后端事件接收仍待接入。

1.6.4：输入框最右侧常驻纸飞机发送图标（空白禁用，48dp点击区域），与输入法发送共用提交；点击输入区外收起键盘且保留草稿，输入和导航不受影响。聊天尚未连接真实服务，继续展示暂未发送。
