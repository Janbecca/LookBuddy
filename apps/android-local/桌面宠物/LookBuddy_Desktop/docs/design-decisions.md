# 第一轮验收：本地桌面宠物

主参考：用户提供的 5 组 GIF，棕色帽子、编织材质和场景道具。Refero 在线服务返回 NO_SUBSCRIPTION，使用技能内 craft-details.md（焦点、图片尺寸、语义控件）和 motion.md（短反馈、不加无意义循环动画）补充。

| 决策 | 来源 | 用途 |
| --- | --- | --- |
| 完整保留宠物、沙发、电脑和道路 | 用户 GIF | 场景保持原貌；去绿幕后按全部帧联合边界裁切 |
| 气泡仅显示 GIF 原文件名、不带后缀 | 用户明确要求 | 与动作一一对应，不添加聊天文案 |

此版本本地运行，没有连接任何云端，没有假连接状态。第二轮在视觉和交互验收通过后接入真实云端协议。

## 连续等比缩放

用户要求通过边框拖动连续调整大小、保持比例。沿用现有素材和棕色控件风格，不引入新的视觉体系。

- 固定 460 × 460 的逻辑画布，按窗口边长统一缩放宠物、气泡及工具条，素材保持自身比例。
- 工具条“调整大小”及右键同名入口打开选框，四角和四边均可拖动；对边中点或对角保持固定。
- 根据用户指定范围，限制边长为 138–920 DIP（30%–200%），上限同时受当前屏幕工作区和固定锚点限制。30% 下缩放控件采用紧凑布局，保留完成和重置入口。
- 显示实时百分比；拖动期间不使用过渡动画；编辑模式暂停自动轮播，结束后恢复。
- 点击完成或按 Esc / Enter 收起选框，恢复透明区域穿透。新尺寸自动保存，旧版大中小偏好自动迁移。

## 托盘统一设置入口

根据用户最新要求，移除下方工具条、动作计数、品牌横条及提示文案。日常桌面仅显示动图与气泡，拖动动图或气泡仍可移动宠物。动图右键不再弹出设置菜单。

全部设置集中到 Windows 系统托盘图标：动作选择、上一个 / 下一个、暂停 / 继续、轮播、气泡、连续大小调整、重置、显示 / 隐藏和退出。仅在主动调整大小时临时显示边框和完成 / 重置控件，结束后收起。

## 普通拖拽与置顶修复

实测旧实现点击 12 次时窗口从 464 DIP 增至 476 DIP；仅改用 Electron setPosition 仍会使 24 次拖拽从 464 增至 488。问题来自 Windows 150% DPI 下重新提交窗口矩形时的取整累积。

现实现用 Koffi 调用应用自身窗口的 SetWindowPos，普通拖拽固定 NOSIZE / NOZORDER / NOACTIVATE，缩放独立受 resizeMode 门控。单击和 3 DIP 以内抖动不移动。松开和丢失指针捕获分别处理，取消事件不拿无效坐标更新尺寸。

置顶采用 Electron screen-saver 层级及原生 HWND_TOPMOST，后者固定 NOMOVE / NOSIZE / NOACTIVATE。显示、失焦、恢复及每秒检查恢复置顶。托盘菜单展开时暂停恢复，以免覆盖菜单；用户主动隐藏时不自动弹回。

依据：[SetWindowPos 官方文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)、[Electron BaseWindow](https://www.electronjs.org/docs/latest/api/base-window)、[Koffi 指针文档](https://koffi.dev/pointers)。
